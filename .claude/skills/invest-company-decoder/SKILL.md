# 기업 해독기 (Company Decoder)

목표: 10분 안에 이 회사를 이해하게 만드는 **한 장 요약 카드**. 매매 판단은 하지 않는다.

## 시작 전에 (모든 투자 스킬 공통)
1. `docs/invest/principles.md`(절대 규칙)와 `docs/invest/bundle-format.md`(출력 형식)를 읽는다.
2. 포트폴리오 컨텍스트: `.data/*.invest.json`이 있으면 `holdings`(ticker·name·assetType·currency·sector), `watchlist`, `themes`, `events`만 읽는다. 없으면(배포 모드) 사용자에게 보유·관심 종목을 묻는다. 수량·평균단가는 필요할 때만 쓴다.
3. 오늘 날짜와 시간대(기본 Asia/Seoul)를 확인한다.

## 모드
- **웹 모드** (티커만 받음): 웹 검색. 출처는 URL만 적는다. 페이지 번호를 붙이지 않는다.
- **문서 모드** (10-K·사업보고서 PDF/파일 경로를 받음): 파일을 직접 읽고 모든 숫자에 `{ "label": "<문서명>", "page": N }` 출처를 단다. 읽지 않은 페이지를 인용하지 않는다.

## 절차
1. 최근 회계연도 사업보고서(미국: 10-K, 한국: DART 사업보고서)와 최근 실적 발표 자료를 찾는다.
2. 리포트 본문(`reports[0]`, skill `decoder`)을 이 순서로 쓴다:
   1. **한 줄 정의** — 누구에게 무엇을 팔아 어떻게 돈을 버는가
   2. **돈 버는 구조** — 텍스트 화살표 다이어그램 (고객 → 제품/서비스 → 매출원 → 비용 구조)
   3. **매출 분해** — 사업부문별 표 + 지역별 표 (최근 회계연도, 금액·비중, 각 행 출처)
   4. **업종 핵심 지표** 3~5개 — 업종에 맞게 고른다 (구독=이탈률·ARPU·NRR, 제조=가동률·수율·재고일수, 소매=동일점포매출·객단가, 은행=NIM·연체율, 플랫폼=MAU·테이크레이트). 값을 못 찾으면 `[확인 필요]`
   5. **경쟁 구도와 해자** — `[사실]`/`[해석]` 구분
   6. **더 파볼 곳** — 다음에 확인할 질문 3개 (예: "스토리 리더로 서비스 부문 가이던스 톤 확인")
   7. **`[원문 재확인 필요]`** — 판단에 쓰일 핵심 숫자 목록
3. 찾은 김에 역DCF 입력값(주가·희석주식수·순부채·FCF 이력·매출 이력, 모두 출처)을 `valuations`에 넣는다. 확실하지 않으면 생략한다.
4. 다음 실적 발표일을 찾으면 `events`에 넣는다.

## 저장 (모든 투자 스킬 공통)
1. 번들을 `invest-inbox/drafts/<YYYYMMDD-HHMM>-<스킬>[-<TICKER>].json`에 쓴다.
2. `npm run -s invest -- check <파일>`로 검증한다. `WARN`이 나오면 원인을 고친다(출처 추가, 매매 표현 제거, 웹 출처의 페이지 번호 삭제). 고칠 수 없으면 그대로 두고 사용자에게 알린다.
3. `npm run -s invest -- save <파일>`로 `invest-inbox/`에 넣는다. 로컬 앱은 화면을 열 때 자동으로 가져간다. 배포 앱을 쓰면 사용자에게 파일을 **가져오기** 화면에 올리라고 안내한다.
4. 채팅에는 리포트 본문 요약과 "원문 재확인 필요" 목록, 저장 경로를 보여 준다. 매매 의견으로 끝맺지 않는다.
