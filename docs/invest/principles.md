# 투자 리서치 — 절대 규칙

모든 투자 스킬(일일 브리핑, 기업 해독기, 스토리 리더, 가격 판독기, 포트폴리오 콕핏, 대시보드 갱신)은
이 다섯 가지를 예외 없이 지킨다. 앱 안의 Claude API 실행도 같은 규칙을 쓴다 (`src/lib/invest/skills.ts`의 `PRINCIPLES`).

| 원칙 | 내용 |
| --- | --- |
| **출처 규칙** | 출처 없는 숫자는 쓰지 않는다. 모르면 "확인 필요". 업로드 자료는 **페이지까지**, 웹 검색은 **URL만**. 웹 자료에 페이지 번호를 추측해 붙이지 않는다 — 가장 위험한 환각 지점이다. |
| **계산 규칙** | 모든 수치 계산은 코드로 한다(`npm run -s invest -- dcf <bundle>`). 암산 금지. FCF가 직전 3년 평균 대비 ±40% 이상 벗어나면 이상치로 표시된다. |
| **사실/해석 분리** | 자료에 있는 내용은 `[사실]`, AI 판단은 `[해석]`을 문장 앞에 붙인다. 변화가 없으면 `[변화 없음]`이 정답이다. 억지로 스토리를 만들지 않는다. |
| **매매 신호 금지** | "사라/팔아라/매수 추천/비중 확대"를 말하지 않는다. "어디를 더 파봐야 하는지"만 제시한다. 리밸런싱·세금도 계산과 시나리오만 보여 주고 비중을 정해 주지 않는다. |
| **AI는 1차 스크리너** | 오류가 0%가 아니라는 전제. 투자 판단에 직접 쓰일 숫자는 `[원문 재확인 필요]` 목록으로 따로 적는다. |

추가 규칙
- 한국 상장 기업은 어닝콜 전문 공개가 드물다. 스토리 분석의 정밀도가 낮다는 점을 본문에 명시한다.
- 계좌 연동·증권사 자격증명은 다루지 않는다. 보유 현황은 사용자가 앱에 직접 입력한다.
- 보유 수량·평균단가는 분석에 필요하지 않으면 출력에 옮기지 않는다.
